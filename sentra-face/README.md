# Sentra Face — talking-face avatar (add-on)

A browser userscript that overlays a 4-state PNGTuber-style avatar on Open WebUI
and animates the mouth from the backend text-to-speech `<audio>` element's
amplitude. **Optional** — the stack runs fine without it.

**Not a Docker service.** This is a client-side userscript (Tampermonkey /
Violentmonkey) plus four PNG frames. Nothing to build or deploy server-side.

## What's in here

| File | Purpose |
|------|---------|
| `sentra-face.user.js` | Network build (desktop) — loads PNGs from an asset server |
| `sentra-face-embedded.user.js` | Embedded build (phone) — frames base64-embedded, zero network |
| `assets/sentra-face2.zip` | The 4-state rig (idle / talk / blink / talk_blink), 1152×1648 RGBA |
| `sf-embed-build.py` | Generator for the embedded build (pure-stdlib, deterministic) |

## Install

### 0. Point it at your Open WebUI

Both builds ship with a default `@match` line. **Edit it to match your Open WebUI
address** before installing:

```
// @match        *://YOUR-OPEN-WEBUI-IP-OR-HOST/*
```

If you open Open WebUI at more than one address (LAN IP, hostname, VPN), add a
`@match` line for each.

### Desktop (Brave / Chrome / Firefox)

1. Install **Violentmonkey** (or Tampermonkey).
2. Open the userscript manager → create a new script.
3. Paste the full contents of `sentra-face.user.js` → save.
4. Open Open WebUI — the face appears on the right after a moment.

> The network build fetches the four PNGs from an asset server. By default it
> points at a private LAN file server — either host the PNGs yourself and edit
> `ASSET_BASE` at the top of the script, or use the embedded build (below),
> which needs no server.

### Phone (Firefox for Android)

1. Install **Tampermonkey** from Firefox Add-ons.
2. Open `sentra-face-embedded.user.js` in a tab → install (or copy-paste into a
   new script).
3. Open Open WebUI — the face appears bottom-right as a draggable bubble.

The embedded build has all four frames baked in as data URLs, so it works with
no asset server and no cross-origin fetches (which phone Firefox blocks).

## Tuning (browser console, on the Open WebUI tab)

The mouth auto-calibrates to the speech's own volume — no threshold to set.

```js
SENTRA_FACE.debug(true)        // HUD: rms/env/peak + thresholds
SENTRA_FACE.state()            // full live state
SENTRA_FACE.setSize(40)        // desktop height in vh (48 default)
SENTRA_FACE.setAuto(false)     // switch to manual threshold
SENTRA_FACE.setThreshold(0.06) // manual mouth-open threshold
SENTRA_FACE.setAuto(true)      // back to auto (recommended)
```

## Troubleshooting

- **No face** → the `@match` doesn't cover the address you're using. Add a line.
- **Face but no mouth** → you're on browser "Web Speech" mode, which has no
  `<audio>` element. Use backend TTS.
- **`audio attach failed`** → reload the page.
